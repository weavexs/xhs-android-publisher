# Repository instructions

- Do not commit account data, device PINs, verification codes, device identifiers, articles, schedules, generated images, or runtime screenshots.
- Preserve explicit public-publish authorization, no-blind-retry behavior, image-order verification, post-publish checks, and screen-off cleanup.
- Every material iteration must update `VERSION` and `CHANGELOG.md`.
- Run the local checks, commit, push, tag the version, and include a concise release summary.
